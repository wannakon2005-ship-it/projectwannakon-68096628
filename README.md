รายละเอียดโครงการ (Project Specifications) ชื่อโครงการ: ระบบบริหารจัดการร้านซักรีดภายในหอพัก (Laundromat Management System) จัดทำโดย: นางสาววรรณกร มากทิม รหัสนักศึกษา: 68096628

วัตถุประสงค์ของโครงการ (Project Objectives) เพื่อสร้างระบบที่ช่วยอำนวยความสะดวกให้ลูกค้าสามารถสั่งบริการซักอบรีดผ่านหน้าเว็บได้ด้วยตนเอง เพื่อช่วยให้เจ้าของร้าน (Admin) บริหารจัดการสถานะผ้าและตรวจสอบรายได้ได้อย่างแม่นยำ เพื่อลดความผิดพลาดในการจดบันทึกข้อมูลและเพิ่มระบบสะสมแต้มเพื่อรักษาฐานลูกค้า

ข้อมูลทางเทคนิค (Technical Stack) ในการพัฒนาระบบนี้ พี่ได้ใช้เทคโนโลยีระดับมาตรฐานอุตสาหกรรม ดังนี้: Frontend: HTML5, CSS3, JavaScript (สำหรับการโต้ตอบที่หน้าเว็บ) Backend Framework: Django (Python) ซึ่งมีความปลอดภัยสูงและจัดการฐานข้อมูลได้ดี Database: Microsoft SQL Server (เชื่อมต่อผ่าน T-SQL) เพื่อความเสถียรของข้อมูล Authentication: ใช้ระบบ Django User Model ในการแยกสิทธิ์ระหว่าง ลูกค้า (Customer) และ พนักงาน/ผู้ดูแล (Admin/Staff)

ฟีเจอร์หลักของระบบ (Key Features)

🔵 สำหรับลูกค้า (Customer Interface) Registration & Login: ระบบสมาชิกเพื่อเก็บประวัติการสั่งซื้อ Service Selection: เลือกรายการผ้าที่ต้องการซัก/รีด แยกตามประเภท (เช่น เสื้อ, กางเกง, ผ้าห่ม) Order Tracking: ติดตามสถานะผ้าได้แบบ Real-time (ซักอยู่, เสร็จแล้ว, รอรับคืน) Point System: ระบบสะสมแต้มอัตโนมัติเมื่อใช้บริการ (เพิ่มความจงรักภักดีต่อแบรนด์)


🔴 สำหรับผู้ดูแลระบบ (Admin Dashboard) Live Dashboard: กราฟและตัวเลขสรุปยอดขาย, จำนวนออเดอร์ใหม่ และสถานะงานค้าง Status Management: อัปเดตสถานะการซักผ้าได้ง่ายๆ เพียงคลิกเดียว User Management: ตรวจสอบรายชื่อสมาชิกและสิทธิ์การเข้าใช้งาน Database Control: เชื่อมต่อกับ SQL Server โดยตรงเพื่อความถูกต้องของข้อมูลทางการเงิน

โครงสร้างฐานข้อมูล (Database Architecture) ระบบประกอบด้วยตารางหลักที่สำคัญ เช่น: Orders: เก็บข้อมูลออเดอร์ วันที่รับผ้า และสถานะ Services: รายการบริการและราคาสินค้า Customers/Profile: ข้อมูลสมาชิกและคะแนนสะสม Payments: บันทึกประวัติการชำระเงินและรูปแบบการจ่ายเงิน
